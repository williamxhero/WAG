# Domain Docs

This repository uses a single-context domain-documentation layout.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant decisions under `docs/adr/` when they exist.
- If these files do not exist, proceed silently; domain-modeling workflows create them when needed.

## Vocabulary

Use terms defined in `CONTEXT.md` consistently in issues, specifications, hypotheses, test names, and implementation plans.

## ADR conflicts

If proposed work contradicts an existing ADR, identify the conflict explicitly instead of silently overriding the decision.
